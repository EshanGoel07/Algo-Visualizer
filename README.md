## 📖 Overview

The **Bellman-Ford Diagnostic Engine** is a highly interactive, web-based educational tool designed to visualize the internal mechanics of the Bellman-Ford pathfinding algorithm. Unlike static graphs, this application provides a dynamic, step-by-step breakdown of how the algorithm calculates shortest paths and detects negative weight cycles in a directed graph.

This project was built to bring transparency to complex Data Structures and Algorithms (DSA) routing mechanics, making it easier to study, debug, and understand graph theory concepts.

## ✨ Key Features

- **Interactive State Arrays:** Real-time tracking of distance values and predecessor references as the algorithm executes.
- **Descriptive Mathematical Logs:** Translates complex algorithmic logic into readable mathematical operations at every iteration.
- **Optimized Execution:** Implements early-convergence logic to terminate the algorithm efficiently if no relaxations occur during a full pass.
- **Responsive UI/UX:** Built using custom CSS design tokens for smooth transitions, dynamic state highlighting, and a dark-themed, card-based dashboard layout.
